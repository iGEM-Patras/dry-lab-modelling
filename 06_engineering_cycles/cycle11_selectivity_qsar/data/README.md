# Cycle 11 working data

`npj_flower_perspective_text.txt` is the extracted text of an open-access Perspective
(doi:10.1038/s44386-026-00046-5), redistributable under CC BY with attribution.

`trgpcr_extracted_text.txt` was removed on 25 Oct 2026, before this repository transferred to
the iGEM Patras organisation. It held 8797 words of extracted text from an IEEE Journal of
Biomedical and Health Informatics paper (doi:10.1109/JBHI.2023.3307928) whose own footer
states that republication and redistribution require IEEE permission. Publishing it here was
redistribution.

Nothing depended on the file. The finding drawn from that paper, its reported RMSE of 1.804
pKd and the reasoning that excludes the method for this project, is recorded with full
citation in `BINDPRED_REJECTED.md`, `CYCLE11_RESULTS.md` and
`../../cycle12_pose_independence/METHODS_REFERENCE_ANALYSIS.md`. Readers should obtain the
paper from IEEE.

Removing the file from the current tree does not remove the blob from git history. Doing that
requires rewriting published history, which has not been done.
