# 05 · Presentation & outreach

Materials for presenting the dry-lab package to the wet lab and to iGEM judges.

| File | Purpose |
|---|---|
| `wetlab_handout.md` / `.pdf` | One-page bench decision sheet: which plasmid, QC gel, which siRNAs to order, how to co-formulate. |
| `slides.html` / `.pdf` | 8-slide deck (landscape) covering the therapeutic idea and all four workstreams, ending with the co-formulation rationale and honest limitations. Open the HTML in a browser to present; the PDF is for handout/printing. |
| `igem_model_alignment.md` / `.pdf` | Self-audit mapping the modelling work to the iGEM judging framework (2026 Special-Award/Gold structure), with a deliverables checklist and a drop-in 150-word Best Model form description. |

All numbers in these materials trace to the consolidated project brief
(`docs/project_brief.pdf`) and the methods log (`docs/methods_references.md`).
