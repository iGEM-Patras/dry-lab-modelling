# Reference — not redistributed

The in-vitro peptide-production method underlying `07_invitro_penk/` is:

> Ozawa, Akihiko; Cai, Yang; Lindberg, Iris (2007). Production of bioactive peptides in an in vitro system. *Analytical Biochemistry* 366(2), 182-189. https://doi.org/10.1016/j.ab.2007.04.020

The publisher PDF is **deliberately not included in this repository** — it is copyrighted and
this repository feeds a public wiki. Access it through your institutional subscription or the
DOI above. What the paper contributes to the design is summarised, with the parameters actually
used, in [`INVITRO_PENK_README.md`](INVITRO_PENK_README.md) and
[`PENK_INVITRO_PROTOCOL.md`](PENK_INVITRO_PROTOCOL.md).
