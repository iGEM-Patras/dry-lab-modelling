# 11, Wet-lab protocols & amendments

Bench-facing documents. Each amendment is a **change to the wet-lab plan that follows from a
dry-lab finding**, written so it can be actioned without reading the modelling.

- `en/`: amendments 1–5 in English (markdown + PDF)
- `gr/`: Greek versions, plus the original wet-lab guide (`ANALYSI_THEMATOS_wetlab_guide_GR.docx`)
  and the bibliography documents the team maintains
- `lipoplex/`: formulation protocol and the one-page bench handout

The error audit of the original Greek guide lives in
[`../08_checkable_audit/tables/guide_error_audit.csv`](../08_checkable_audit/tables/guide_error_audit.csv):
**17 findings: 5 critical, 9 moderate, 3 minor**, each with a reference and a correction.
